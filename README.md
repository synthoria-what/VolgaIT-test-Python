# UI-тесты Practice Automation

Python 3.12+, Selenium, pytest. Всего 31 тест: по 7 позитивных и 3 негативных на календарь, модальные окна и рекламу, плюс проверка Message.

## Запуск

Нужны Chrome или Firefox и интернет. Команды для PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest --headless --clean-alluredir
```

Для Firefox добавьте `--browser firefox`. Для видимого окна уберите `--headless`.

## Allure

Для сборки HTML нужен Node.js с npm:

```powershell
npx --yes allure@3.21.0 awesome allure-results --single-file --output allure-report
```

Открыть `allure-report/index.html`. При ошибке скриншот сохраняется в `screenshots` и прикладывается к отчёту.

## Сценарии

**Календарь** (`/calendars/`)

- Позитивные: открытие календаря; выбор дня текущего, следующего и предыдущего месяца; ввод правильной даты; ввод 29 февраля високосного года; очистка поля. Выбранная дата сохраняется, после очистки поле пустое.
- Негативные: текст вместо даты; 30 февраля; формат `ДД/ММ/ГГГГ`. Ожидается ошибка поля.

**Модальные окна** (`/modals/`)

- Позитивные: открытие простого окна с текстом; закрытие крестиком; повторное открытие; открытие формы с тремя полями; закрытие формы крестиком; закрытие по Escape; заполнение полей с проверкой значений.
- Негативные: пустое имя; Email без `@`; Email без имени пользователя. После Submit ожидается ошибка, форма не отправляется.

**Реклама** (`/ads/`)

- Позитивные: автоматическое появление с текстом; закрытие крестиком; закрытие по Enter; повторное появление после обновления; переход по логотипу после закрытия; доступность крестика и закрытие в окне 600×900; отсутствие повторного появления в течение 6 секунд после закрытия.
- Негативные: Escape и клик по затемнению не закрывают рекламу; клик по логотипу за рекламой блокируется.

**Message** (`/form-fields/`): получить список Automation tools через Selenium и заполнить Message названиями через запятую. Значение поля должно совпасть со списком.

Успешная отправка валидных форм на сервер не проверяется. Результаты запуска — в [TEST_RESULTS.md](TEST_RESULTS.md).
